# Sheba Travels International (Next.js)
`npm install && npm run dev`
Drop your files in `public/images/`: logo.png, next-tawaf-logo.png, hero-kaaba.jpg, hero-flight.jpg.
Edit prices, WhatsApp number and video paths in `lib/data.js`. Footer details in `components/Footer.jsx`.

To enable quote emails, copy `.env.example` to `.env.local` and set `SMTP_USER` and
`SMTP_PASSWORD` to a Gmail account and App Password. `SMTP_RECIPIENT` controls
where booking notifications are delivered.
